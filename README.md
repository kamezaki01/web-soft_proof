# ソフトプルーフ

画像を CMYK で印刷したときの色を、ブラウザで確かめるツールです。コンビニのマルチコピー機などで刷る前に、色がどれくらい変わるか、どこが印刷では出せない色かを見るために使います。

- HTML ファイル 1 つで動きます。サーバーもインターネット接続もいりません。
- 画像とプロファイルはブラウザの中だけで処理します。外には送りません。
- 色の変換には Little CMS（ICC プロファイルによる色変換エンジン）を使っています。

## 使い方

1. `softproof.html` をブラウザで開く（ダブルクリックでよい）
2. 画像（PNG / JPEG / WebP）をドラッグ＆ドロップする
3. プリンターのアイコンで CMYK プロファイル（.icc / .icm）を選ぶ
4. 右側（印刷）で、刷ったときの見た目を確かめる

一度選んだプロファイルはブラウザに保存され、次に開いたときも使われます。

## CMYK プロファイル

ライセンスの都合で、プロファイルはツールに入れていません。各自で用意してください。

| 刷り方 | 近いプロファイル | 入手先 |
|---|---|---|
| 普通紙のカラーコピー・プリント | Japan Color 2001 Uncoated | Adobe ICC Profiles（無料） |
| 光沢紙・ハガキ | Japan Color 2001 Coated | Adobe ICC Profiles（無料） |
| 汎用 | Generic CMYK Profile | macOS の `/System/Library/ColorSync/Profiles/` |

コンビニの機械のプロファイルは公開されていません。どのプロファイルで見ても目安です。L 判などの写真プリントは別の仕組みで刷るので、このツールの結果は当てはまりません。

## 機能

- **変換の設定**：レンダリングインテント（知覚的 / 相対的な色域を維持 / 彩度 / 絶対的な色域を維持）、黒点の補正、紙の白の再現
- **比べ方**：左右に並べる / スライダーで比べる / 押している間だけ元の画像
- **色域外の警告**：元の色と印刷後の色の差（ΔE2000）がしきい値を超える画素に印を付け、その割合を表示
- **スポイト**：カーソル位置の元の RGB・CMYK（%）・印刷後の RGB・ΔE を表示
- **色の調整**：明るさ・コントラスト・彩度・暖かさ。狙った色に近い部分だけを直す部分調整（色相・彩度・明るさ）もある
- **書き出し**：印刷後の見た目（色域外の印付きも可）と、調整した画像を PNG で保存

操作：ホイールで拡大縮小、ドラッグで移動、ダブルクリックまたは `0` キーで全体表示、`1` キーで等倍。

## しくみ

1. 元の画像の色を CMYK に変換する（選んだインテント・黒点の補正）
2. その CMYK を画面用の sRGB に戻して表示する（紙の白を再現するときは絶対的な色域を維持で戻す）
3. 元の色と、CMYK を経由した色をそれぞれ Lab にして ΔE2000 を計算する。紙の色は含めない

- 画像に ICC プロファイルが埋め込まれていればそれを使い、なければ sRGB として扱います。
- 変換は Web Worker で行うので、4000 × 3000 程度の画像でも画面は固まりません（変換に 1〜2 秒）。

## ブラウザ

Chrome / Edge / Firefox を想定しています。Safari は、埋め込みプロファイル付きの画像で色が二重に変換される可能性があります（未確認）。
